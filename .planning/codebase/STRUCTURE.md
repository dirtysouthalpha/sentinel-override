## Directory Purposes

**Root Directory (`./`):**
- Purpose: Chrome extension root directory
- Contains: All extension files as required by Chrome Manifest V3
- Key files: `manifest.json` (entry point), `background.js`, `content.js`

**`.planning/codebase/` (Planning documents directory):**
- Purpose: Architecture and planning analysis documents
- Contains: ARCHITECTURE.md and STRUCTURE.md
- Generated by: GSD mapping process

**`docs/`:**
- Purpose: Documentation and screenshots
- Contains: PNG images for README (screenshots)
- Generated files: Documentation assets

## Key File Locations

**Entry Points:**
- `manifest.json`: Chrome extension manifest and permissions
- `background.js`: Service worker entry point, agent loop
- `popup.html`: UI container, CSS themes, basic HTML structure
- `popup-full.js`: UI logic event handlers and state management

**Core Logic:**
- `background.js`: Agent planning, API calls, self-healing (1797 lines)
- `content.js`: Element scanning, action execution, iframe support (591 lines)
- `popup-full.js`: UI management, message handling, themes (1258 lines)

**Configuration:**
- `manifest.json`: Extension settings, permissions, manifest version
- `popup-full.js`: Settings modal and configuration handling

**Testing:**
- No dedicated test files detected
- Testing relies on manual verification and Chrome extension testing tools

## Naming Conventions

**Files:**
- Lowercase with hyphens: `background.js`, `popup-full.js`
- Exception: `marked.min.js` (external library with standard naming)

**Functions:**
- camelCase: `runAgentLoop`, `executeCommand`, `sendMessageWithRetry`
- Constants: UPPER_SNAKE_CASE: `CONFIG`, `MAX_DEPTH`

**Variables:**
- camelCase: `agentMemory`, `currentPlanStep`, `apiCallCount`
- Private variables: Leading underscore (rare)

## Where to Add New Code

**New Feature Extension:**
- Agent features: Add to `background.js` (main logic) or `content.js` (DOM interactions)
- New action type: Add to both `background.js` (command processing) and `content.js` (execution)

**New UI Component:**
- HTML structure: Add to `popup.html`
- Logic and styling: Add to `popup-full.js`
- CSS themes: Add to CSS section in `popup.html`

**New Platform Support:**
- Platform detection: Add to `getPlatformContext()` in `background.js`
- Platform-specific rules: Add as new section in platform detection

**New Settings:**
- UI: Add to settings modal in `popup-full.js`
- Storage: Add to Chrome storage operations in `background.js`
- Configuration: Add to settings modal handlers

**New Theme:**
- CSS variables: Add to CSS in `popup.html`
- Theme preset: Add to `applyThemePreset()` in `popup-full.js`
- Theme class: Add CSS rules in `popup.html`
