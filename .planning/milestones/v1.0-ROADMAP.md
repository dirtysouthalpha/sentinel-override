## Overview

MediaSentinel is an intelligent monitoring and auto-recovery system for a home media stack. v1.0 delivers the complete system: config, logging, SQLite, monitoring for 8 services, VPN enforcement, 7-level recovery, qBittorrent integration, TUI dashboard, alerting, metrics, and Windows/Docker deployment.

## Milestone Summary

**Key Decisions:**
- Python 3.10+ with async (asyncio, httpx) chosen for monitoring ecosystem
- SQLite with WAL mode for concurrent access (no external DB dependency)
- APScheduler 3.11.2 over 4.x (4.x is pre-release)
- Pydantic 2.x with extra='forbid' for strict config validation
- Textual 8.2.5 for TUI (not just Rich)
- NSSM preferred over pywin32 for Windows service registration
- Shutdown snapshots are single-use (consumed and deleted on restore)
- Docker HEALTHCHECK does NOT auto-restart — MediaSentinel handles this

**Issues Resolved:**
- Loguru serialize=True nests custom fields under record.extra, not top-level
- APScheduler 3.x uses add_job(), not add_schedule() (verified)
- Windows paths use %PROGRAMDATA%\MediaSentinel\ for logs and database
- qBittorrent v4/v5 API differences handled via version-aware wrapper

**Issues Deferred:**
- None — all v1 requirements implemented

**Technical Debt:**
- test_tunnel_restart_success may have intermittent failure (pre-existing, recovery engine)
- No Prometheus/Grafana integration (deferred to v2 per requirements)
- No multi-VPN provider support (deferred to v2 per requirements)
