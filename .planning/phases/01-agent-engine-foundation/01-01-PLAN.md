  <name>Task 1: Create message-protocol.js and refactor content.js error handling</name>
  <files>background/message-protocol.js, content.js</files>
  <action>
Create `background/message-protocol.js` with these exports:

1. `sendMessage(tabId, message, timeoutMs = 10000)` -- Promise wrapper around chrome.tabs.sendMessage. Checks chrome.runtime.lastError, rejects on error, rejects if response.ok is false, resolves with response.data.

2. `sendRuntimeMessage(message)` -- Promise wrapper around chrome.runtime.sendMessage for popup-to-background communication. Checks chrome.runtime.lastError, rejects on error, resolves with response.

3. `wrapMessageHandler(asyncHandler)` -- Returns a (request, sender, sendResponse) => true function that wraps an async handler. Calls asyncHandler(request, sender), on success calls sendResponse({ ok: true, data: result }), on failure calls sendResponse({ ok: false, error: err.message }). Always returns true to keep message channel open.

This module imports NOTHING from other background modules (pure utility, no circular dependency risk).

Then refactor `content.js`:
- Add a `window.__sentinelInitialized` guard at the top. If already set, just send `content_script_ready` and return early (no re-registration of listeners, no duplicate MutationObservers later).
- Wrap the existing onMessage listener using the { ok, data, error } pattern. The listener should be: `chrome.runtime.onMessage.addListener((request, sender, sendResponse) => { handleMessage(request).then(data => sendResponse({ ok: true, data })).catch(err => sendResponse({ ok: false, error: err.message })); return true; });`
- Move the switch/case logic into an `async function handleMessage(request)` that returns data on success and throws on failure.
- For `observe_page`: return `{ elements: interactiveElements }` (not `{ elements: ... }` bare).
- For `read_page`: return `{ content: ... }` (not bare `{ content: ... }`).
- For `execute_command`: call executeCommand(cmd). Success stays as returned string. If executeCommand returns a string starting with 'Error' or 'Element not found', throw new Error(result) instead of returning it. The old `sendResponse({ result: 'Error: ' + err.message })` pattern goes away.
- For `wait_for`: call handleWaitFor(request.condition), return the result. If it throws, let the wrapper catch it.
- Keep the `__sentinelInitialized` guard simple -- this is a first pass. Full SPA observer setup comes in plan 01-02.

IMPORTANT: content.js does NOT import message-protocol.js (content scripts can't use ES module imports). It just follows the same envelope pattern manually. The shared pattern is the contract, not a shared module.
  </action>

```javascript
import { wrapMessageHandler, sendSilentUpdate, sendActionMessage, sendActionResult } from './message-protocol.js';

// Tab locking (from lines 27-30)
chrome.action.onClicked.addListener((tab) => { ... });

// Unified message handler
chrome.runtime.onMessage.addListener(wrapMessageHandler(async (request, sender) => {
  switch (request.action) {
    case 'execute_command': {
      if (!agentTabId) throw new Error('No agent tab specified');
      // Handle navigate inline (no content script needed)
      if (request.command.type === 'navigate') {
        if (!isValidUrl(request.command.url)) throw new Error('Invalid URL provided');
        await chrome.tabs.update(agentTabId, { url: request.command.url });
        return 'Navigated to ' + request.command.url;
      }
      // All other commands: inject content script, send message
      await injectContentScript(agentTabId);
      return await sendMessageWithRetry(agentTabId, { action: 'execute_command', command: request.command });
    }
    case 'run_agent_loop': return await startAgent(request.goal, sender);
    case 'stop_agent_loop': return stopAgent();
    // SPA messages from content script (handled in 01-02)
    case 'spa_navigation':
    case 'spa_content_changed': return null;
    default: throw new Error(`Unknown action: ${request.action}`);
  }
}));
```

IMPORTANT: All imports are static (top-level). No dynamic `import()` calls. All modules are imported once at the top and referenced throughout.
