    **1. core/__init__.py** -- Export `Orchestrator` from orchestrator.py.

    **2. core/orchestrator.py** -- Create:
    - `class Orchestrator`:
      - `__init__(self, config: AppConfig)`:
        - Store config as self.config
        - Create AsyncIOScheduler with job_defaults: coalesce=True, max_instances=1, misfire_grace_time=30
        - Do NOT start scheduler in __init__ (start is separate)
      - `async def initialize(self)`:
        - Call setup_logging(self.config.logging)
        - Call init_db(Path(self.config.database.db_path))
        - Log "Orchestrator initialized" via loguru with component="Orchestrator"
      - `async def start(self)`:
        - Call await self.initialize() if not already initialized
        - Start scheduler: self.scheduler.start()
        - Log "Scheduler started" via loguru
        - Keep running via asyncio.Event wait (block until shutdown signal)
      - `async def shutdown(self)`:
        - Shutdown scheduler: self.scheduler.shutdown(wait=False)
        - Log "Orchestrator shut down" via loguru
      - `add_health_check_job(self, service_name: str, interval_seconds: int)`:
        - Use self.scheduler.add_job() (3.x API, NOT add_schedule)
        - trigger=IntervalTrigger(seconds=interval_seconds)
        - id=f"health_{service_name}"
        - name=f"Health check: {service_name}"
        - replace_existing=True
        - The actual job callback is a placeholder coroutine that logs the check (real health checks in Phase 2)
    - Use `loguru.logger.bind(component="Orchestrator")` for all orchestrator log messages
