<objective>
Create the TabContext manager module and integrate it into the agent engine, replacing the single agentTabId with a multi-tab context map. The agent loop becomes tab-aware: it opens, switches between, and closes tabs during task execution, with per-tab screenshot caches and automatic cleanup.

Purpose: This is the foundation for all multi-tab workflows. Without a tab context manager, the agent can only operate on one tab at a time.

Output: A working tab-context.js module integrated into agent-engine.js such that the agent loop operates on whichever tab is currently "active" in the context map, and can open/switch/close tabs as discrete actions.
</objective>

  <name>Task 1: Create tab-context.js module with TabContext map, open/switch/close, and snapshot management</name>
  <files>background/tab-context.js</files>
  <action>
Create `background/tab-context.js` as a new ES module that manages multi-tab state. This module is the single source of truth for which tabs the agent is tracking and which one is active.

**TabContext shape:**
```javascript
{
  tabId: number,
  label: string,           // Human-readable label (e.g., "SonicWall Logs")
  url: string,             // Current URL
  title: string,           // Page title
  isActive: boolean,       // Agent is currently operating on this tab
  snapshot: {              // Last page snapshot (updated on action)
    elements: Array,
    pageContent: string,   // Truncated
    timestamp: number,
  },
  screenshotCache: {
    cachedBase64Image: string|null,
    lastScreenshotUrl: string|null,
  },
  createdAt: number,       // For LRU eviction
  isAgentCreated: boolean, // True = agent opened it, False = user's existing tab
}
```

**Required exports:**
- `getActiveTabId()` -- returns the currently active tab ID (null if none)
- `setActiveTab(tabId)` -- sets the active tab, deactivating the previous one
- `getTabContext(tabId)` -- returns TabContext for a specific tab
- `getAllTabContexts()` -- returns array of all tracked TabContexts
- `getTabCount()` -- returns number of tracked tabs
- `openTab(url, label)` -- creates a new tab via chrome.tabs.create({url, active: false}), registers it in the map. If at TAB_LIMIT (5), evict oldest non-active tab first. Return the new TabContext.
- `switchToTab(tabId)` -- calls chrome.tabs.update(tabId, {active: true}) then setActiveTab(tabId). Return true on success.
- `closeTab(tabId)` -- removes from map. If agent-created, calls chrome.tabs.remove. If it was active, switch to another tracked tab or null. Return void.
- `closeAllAgentTabs()` -- batch-close all agent-created tabs, clear map, reset activeTabId. Used at agent loop end.
- `updateSnapshot(tabId, snapshot)` -- updates the snapshot field on a TabContext and syncs url/title.
- `resetAllContexts()` -- clear the entire map and activeTabId. Used on agent reset.
- `findTabByLabel(label)` -- find tab context by label string (for LLM command resolution).
- `registerInitialTab(tabId, url)` -- register the user's starting tab as a non-agent-created tab with label "Main Task Tab" and isActive: true. Called once at agent start.
- `TAB_LIMIT` -- constant set to 5.

**Import from:**
- `./message-protocol.js` -- import `sendTabStateUpdate` (will be created in this same task)
- `./tab-manager.js` -- import `waitForPageLoad`, `getTabInfo` (for URL/title updates)

**Key implementation details:**
- In-memory `Map<tabId, TabContext>` as the primary store
- `chrome.tabs.onRemoved` listener to clean up externally-closed tabs (user closes a tracked tab). Register this listener in index.js, not here -- export a `handleTabRemoved(tabId)` function that index.js calls from its listener.
- After every state change (open/close/switch), call `sendTabStateUpdate(getAllTabContexts())` to notify the popup.
- `openTab` should use `chrome.tabs.create({url, active: false})` -- do NOT steal focus from the user's current tab.
- LRU eviction in `openTab`: if at TAB_LIMIT, find the oldest non-active tab (by createdAt), call closeTab on it before creating the new one.
- `closeTab` should NOT throw if the tab was already closed by the user -- wrap chrome.tabs.remove in try/catch.
- `findTabByLabel` does case-insensitive partial matching for resilience.

**Also in this task:** Add `sendTabStateUpdate(tabs)` export to `background/message-protocol.js`. This helper sends `{ action: 'tab_state_update', tabs: [...] }` to the popup, where each tab is a sanitized object with `{ tabId, label, url, isActive }`. Use `chrome.runtime.sendMessage` with `.catch(() => {})` to handle no-listener case.

**Also in this task:** Add description cases for tab command types to the `sendActionMessage` function in `background/message-protocol.js`. Find the existing switch/if-else that maps command types to human-readable descriptions (e.g., `click` → "Click element", `navigate` → "Navigate to URL"). Add three new cases:
- `open_tab` → `"Open tab: ${command.label || command.url}"`
- `switch_tab` → `"Switch to: ${command.label || command.tab_id}"`
- `close_tab` → `"Close tab: ${command.label || command.tab_id}"`

This ensures the popup displays proper action cards for tab operations instead of a bare "open_tab" string.

**Also in this task:** Add no imports or changes to `background/shared-state.js` in this plan -- shared-state stays as-is (SPA flags only). The tab context is fully self-contained in tab-context.js.

**Important anti-patterns to avoid:**
- Do NOT replace `agentTabId` with another global variable. Use `getActiveTabId()` everywhere.
- Do NOT allow tab switching mid-observe-execute cycle. Tab switches are discrete actions (open_tab/switch_tab/close_tab) that produce a result and continue to the next loop iteration.

**Scope note on persistence:** Tab context uses an in-memory Map that persists for the duration of a single agent run (the service worker stays alive during active execution).
