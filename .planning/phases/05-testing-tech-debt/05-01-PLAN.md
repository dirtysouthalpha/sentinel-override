    **3. Create tests/helpers/chrome-mock.js -- custom stateful Chrome API mock:**

    Build a lightweight mock covering ~9 Chrome namespaces with ~30 methods. Follow the architecture from STACK.md research but use Vitest's `vi.fn()` instead of Jest's `jest.fn()`. Key requirements:
    - `EventListenerPool` class with `addListener(fn)`, `removeListener(fn)`, `fire(...args)` -- used for `chrome.runtime.onMessage`, `chrome.tabs.onRemoved`, `chrome.tabs.onActivated`, `chrome.alarms.onAlarm`, `chrome.runtime.onInstalled`
    - `createStorageMock()` -- stateful: `set({key: val})` then `get('key')` returns `{key: val}`. Support both callback and Promise patterns. Expose `_store` for direct assertions.
    - `createTabsMock()` -- stateful Map of tabs. `create({url})` adds to map and returns tab object. `get(tabId, callback)` fires callback with tab. `query({active: true}, callback)` filters and fires callback. `update(tabId, props)` mutates tab. `remove(tabIds)` deletes from map. `sendMessage(tabId, msg, callback)` fires callback. Expose `_tabs` for assertions.
    - `createRuntimeMock()` -- `sendMessage(msg, callback)` fires callback with response. `onMessage` as EventListenerPool. `lastError` starts as null (tests set it to simulate errors). `getURL(path)` returns `chrome-extension://mock-id/{path}`.
    - `createAlarmsMock()` -- stateful Map. `create(name, {when, periodInMinutes})` stores alarm. `get(name)` returns alarm. `getAll()` returns all. `clear(name)` deletes. `onAlarm` as EventListenerPool. Expose `_alarms`.
    - `createChromeMock()` assembles all namespaces: storage, tabs, runtime, alarms, scripting.executeScript, debugger (attach/detach/sendCommand), action (setIcon/setBadgeText), sidePanel (open/setOptions), webNavigation (onBeforeNavigate as EventListenerPool).
    - `setupChromeMock()` sets `global.chrome` and returns the mock for per-test access.
