  <name>Task 1: Create template-manager.js with CRUD, parameter extraction, goal resolution, and usage tracking</name>
  <files>background/template-manager.js</files>
  <action>
Create `background/template-manager.js` as a Layer 2 ES module. This module imports NOTHING from other background modules (pure utility + storage). It only uses chrome.storage.local.

**Storage:**
- Key: `sentinel_templates`
- Shape: `{ [id: string]: Template }` (object keyed by ID, NOT an array -- avoids reindexing on every write)
- Template shape:
  ```
  {
    id: string,              // crypto.randomUUID()
    name: string,            // user-defined, min 1 char
    goal: string,            // the goal template text with ::key:: placeholders
    params: Array<{          // extracted from goal text
      key: string,           // the ::key:: name (alphanumeric + underscore)
      label: string,         // display label (defaults to key)
      defaultValue: string,  // empty string if none
    }>,
    tags: Array<string>,     // user-defined tags for filtering
    createdAt: number,       // Date.now()
    updatedAt: number,       // Date.now() on every save
    lastUsedAt: number|null, // Date.now() on run, null if never run
    runCount: number,        // incremented on each run
  }
  ```

**Exported functions:**

1. `listTemplates()` -- Returns all templates as an array, sorted by updatedAt descending. Uses chrome.storage.local.get('sentinel_templates').

2. `getTemplate(id)` -- Returns single template by ID, or null if not found.

3. `saveTemplate(templateData)` -- Creates a new template. Accepts `{ name, goal, params?, tags? }`. If `params` is not provided, auto-extract from goal using `extractParameters(goal)`. Generates ID via crypto.randomUUID(), sets createdAt/updatedAt to Date.now(), lastUsedAt to null, runCount to 0. Stores and returns the complete template object.

4. `updateTemplate(id, updates)` -- Updates an existing template. Accepts partial updates: `{ name?, goal?, params?, tags? }`. If `goal` is updated and `params` is not provided, re-extract params from new goal. Sets updatedAt to Date.now(). Throws if template not found. Returns the updated template.

5. `deleteTemplate(id)` -- Removes template from storage. Throws if not found. Returns void.

6. `extractParameters(goalText)` -- Parses goal string for `::key::` patterns using regex `/:{2}(\w+):{2}/g`. Returns array of `{ key, label, defaultValue: '' }` where label = key with underscores replaced by spaces and title-cased (e.g., "firewall_url" -> "Firewall Url"). Deduplicates by key.

7. `resolveTemplateGoal(templateId, paramValues)` -- Loads template by ID, substitutes all ::key:: placeholders in the goal string with corresponding values from paramValues object. For each ::key:: in the goal:
   - If paramValues[key] is provided and non-empty, use it
   - If paramValues[key] is empty/undefined but template.params[key].defaultValue exists, use the default
   - Otherwise, leave the placeholder as-is (the user skipped an optional param)
   Updates lastUsedAt to Date.now() and increments runCount. Returns the resolved goal string. Throws if template not found.

8. `updateTemplateUsage(templateId)` -- Convenience function called after agent finishes a template run. Sets lastUsedAt = Date.now() and increments runCount. Used when the agent completes (separate from resolveTemplateGoal which is called at start).

**Important constraints:**
- Do NOT import from message-protocol.js, agent-engine.js, or any other background module
- Use only chrome.storage.local for persistence
- Validate inputs: name must be non-empty string, goal must be non-empty string, params must be array of objects with string keys
- All functions are async (because chrome.storage.local.get/set are async)
- Use `/:{2}(\w+):{2}/g` regex for parameter extraction (the delimiter is :: not single colon)

**File header comment:**

**Add 6 new cases to the existing switch statement in wrapMessageHandler (before the `default:` case):**

```javascript
// Template CRUD
case 'template_list':
  return await listTemplates();

case 'template_get':
  if (!request.id) throw new Error('Template ID required');
  return await getTemplate(request.id);

case 'template_save':
  if (!request.template) throw new Error('Template data required');
  return await saveTemplate(request.template);

case 'template_update':
  if (!request.id) throw new Error('Template ID required');
  if (!request.updates) throw new Error('Update data required');
  return await updateTemplate(request.id, request.updates);

case 'template_delete':
  if (!request.id) throw new Error('Template ID required');
  await deleteTemplate(request.id);
  return { deleted: true };

case 'template_run': {
  if (!request.templateId) throw new Error('Template ID required');
  if (agentRunning) throw new Error('Agent already running');
  const goal = await resolveTemplateGoal(request.templateId, request.params || {});
  return await startAgent(goal, sender);
}
```

**DO NOT modify any existing cases or event listeners.** This is purely additive -- insert the 6 new cases before the `default:` throw.

**Message protocol:**
- Popup sends `{ action: 'template_list' }` -> receives `Array<Template>`
- Popup sends `{ action: 'template_get', id }` -> receives `Template | null`
- Popup sends `{ action: 'template_save', template: { name, goal, params?, tags? } }` -> receives `Template`
- Popup sends `{ action: 'template_update', id, updates: { name?, goal?, params?, tags? } }` -> receives `Template`
- Popup sends `{ action: 'template_delete', id }` -> receives `{ deleted: true }`
- Popup sends `{ action: 'template_run', templateId, params: { key: value } }` -> receives `'Agent started in background'`

Note: `template_run` checks `agentRunning` before resolving the goal and starting the agent. This prevents double-starts.
