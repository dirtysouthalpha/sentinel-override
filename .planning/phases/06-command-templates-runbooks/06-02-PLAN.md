  <action>
Create `popup-modules/templates.js` as a regular script (NOT ES module). This follows the Phase 5 popup module pattern: defines global functions, accesses shared state via `getState()`, uses `chrome.runtime.sendMessage` for background communication.

**File header:**
```javascript
// popup-modules/templates.js
// Template library UI: list, search, filter, create, edit, run, delete.
// Depends on: ui-common.js (showToast, sanitizeHtml).
// Communicates with background via chrome.runtime.sendMessage (template_* actions).
```

**State accessor:**
```javascript
const getState = () => window.__popupState;
```

**Required global functions:**

### Panel Toggle
- `showTemplatesPanel()` -- Hides chat-container and input-area, shows templates-panel. Calls `loadTemplates()`. Updates templatesBtn to have `.active` class.
- `hideTemplatesPanel()` -- Shows chat-container and input-area, hides templates-panel. Removes `.active` from templatesBtn.

### Template List
- `loadTemplates()` -- Sends `{ action: 'template_list' }` to background. Renders template cards into `#template-list`. Each card shows: name, goal text (truncated), tags as pills, last-used date (relative: "2 hours ago", "3 days ago", "Never"), run count. Cards have 3 action buttons: Run (primary), Edit (secondary), Delete (danger).

  Use relative time formatting: if lastUsedAt is null, show "Never run". Otherwise, calculate difference from now and show "Xm ago", "Xh ago", "Xd ago", or date string if > 30 days.

  If no templates exist, show empty state: "No templates yet. Create one from a completed task or build one from scratch."

### Search and Filter
- `filterTemplates(templates, searchTerm, tagFilter)` -- Filters the template array. searchTerm matches against name (case-insensitive partial match). tagFilter matches if ANY tag in the template's tags array contains the filter string (case-insensitive partial match). Both filters apply simultaneously (AND logic). Returns filtered array sorted by updatedAt desc.

  Wire `#templateSearchInput` to `oninput` -> `loadTemplates()` (re-fetches and re-filters).
  Wire `#templateTagFilter` to `oninput` -> `loadTemplates()`.

### Create Template
- `openCreateTemplateModal(goalText)` -- If goalText is provided (from "Save as Template" action), pre-fill the goal textarea. Show the template-modal with title "New Template". Clear all fields. Call `updateParamEditor()` on goal input to auto-detect parameters.
- `saveNewTemplate()` -- Read name, goal, tags from form. Send `{ action: 'template_save', template: { name, goal, tags: parseTags(tagsInput) } }` to background. On success, close modal, call loadTemplates(), show toast "Template saved".
- `parseTags(tagString)` -- Split comma-separated string, trim whitespace, filter empty strings, return array.

### Edit Template
- `openEditTemplateModal(templateId)` -- Fetch template via `{ action: 'template_get', id }`. Populate modal fields with template data. Change title to "Edit Template". Store editing templateId in a module-level variable `let editingTemplateId = null`.
- `saveEditedTemplate()` -- Read updated name, goal, tags. Send `{ action: 'template_update', id: editingTemplateId, updates: { name, goal, tags } }` to background. On success, close modal, call loadTemplates(), show toast "Template updated".

### Parameter Editor (in create/edit modal)
- `updateParamEditor()` -- Read goal text from `#tmpl-goal`. Use regex `/:{2}(\w+):{2}/g` to extract ::key:: placeholders. For each unique key, render a row in `#tmpl-params-container`:
  ```
  Label: [auto-detected label]    Default: [input field]
  ```
  The label is derived from the key (underscores to spaces, title-cased). The default value input is pre-filled if editing an existing template (look up param.defaultValue from the template's params array).

  Wire `#tmpl-goal` `oninput` to `updateParamEditor()` so parameters are auto-detected as the user types.

### Run Template
- `openRunModal(templateId)` -- Fetch template via `{ action: 'template_get', id }`. Show `#template-run-modal`. Set title to "Run: {template.name}". Show goal preview (the raw goal with ::key:: placeholders visible). For each param in template.params, render a labeled input field in `#tmpl-run-params-container`. Pre-fill with defaultValue if present. Mark required params (no defaultValue and required=true) -- for now, all params without defaults are considered optional since the user might intentionally leave them for the LLM.
- `executeTemplate(templateId)` -- Read all param values from the run modal inputs. Send `{ action: 'template_run', templateId, params: { key: value, ... } }` to background. On success, close modal, hide templates panel, show chat view (call `hideTemplatesPanel()`). Show toast "Template running...".

### Delete Template
- `deleteTemplate(templateId, templateName)` -- Show a confirmation using `confirm('Delete template "' + templateName + '"? This cannot be undone.')`. If confirmed, send `{ action: 'template_delete', id: templateId }`. On success, call loadTemplates(), show toast "Template deleted".

### Event Wiring
Wire all event listeners at the bottom of the file:
- `#templatesBtn` click -> toggle templates panel (show if hidden, hide if visible)
- `#createTemplateBtn` click -> openCreateTemplateModal()
- `#saveTemplateBtn` click -> saveNewTemplate() or saveEditedTemplate() (check editingTemplateId)
- `#closeTemplateModalBtn` click -> close modal, reset editingTemplateId
- `#runTemplateBtn` click -> executeTemplate(stored templateId)
- `#closeRunModalBtn` click -> close run modal
- `#templateSearchInput` input -> loadTemplates()
- `#templateTagFilter` input -> loadTemplates()

**Important:**
- Use `chrome.runtime.sendMessage` for all background communication (same pattern as chat.js)
- Handle errors with `.catch(err => showToast(err.message || 'Error', 'error'))`
- Use `showToast()` from ui-common.js for all user feedback
- Store run-modal templateId in a module-level variable: `let runningTemplateId = null`
- The "Save as Template" flow: `openCreateTemplateModal(goalText)` can be called from chat.js later (not in this plan -- expose the function globally)
- Relative time helper: `function relativeTime(timestamp) { ... }` returns human-readable string
