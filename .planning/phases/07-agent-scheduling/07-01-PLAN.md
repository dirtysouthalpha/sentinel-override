  <name>Task 1: Create scheduler.js with CRUD, alarm management, and execution bridge</name>
  <files>background/scheduler.js</files>
  <action>
Create `background/scheduler.js` as a Layer 3 module (~280 lines) with the following structure:

**Imports:**
- `import { agentRunning, startAgent } from './agent-engine.js';`
- `import { resolveTemplateGoal } from './template-manager.js';`
- `import { generateReport } from './report-generator.js';`
- `import { getActiveTabId, registerInitialTab } from './tab-context.js';`
- `import { getTabInfo } from './tab-manager.js';`

**Storage constants:**
- `SCHEDULES_KEY = 'sentinel_schedules'`
- `RESULTS_KEY = 'sentinel_schedule_results'`
- `MAX_RESULTS = 50`

**Schedule shape (stored in chrome.storage.local under sentinel_schedules as `{ [id]: Schedule }`):**
```
{
  id: string (crypto.randomUUID()),
  name: string,
  templateId: string | null,
  goal: string | null,
  params: object | null,
  type: 'once' | 'recurring',
  recurrence: {
    interval: 'daily' | 'weekly' | 'custom',
    periodInMinutes: number,       // computed from interval
    daysOfWeek: number[] | null,   // [0-6] for weekly, null otherwise
    time: string,                  // "HH:MM" local time
  } | null,
  enabled: boolean,
  nextRunAt: number | null,        // timestamp ms
  lastRunAt: number | null,
  lastRunStatus: 'success' | 'failure' | 'skipped' | null,
  createdAt: number,
}
```

**Result shape (stored in chrome.storage.local under sentinel_schedule_results as `{ [id]: Result }`):**
```
{
  id: string,
  scheduleId: string,
  scheduleName: string,
  templateId: string | null,
  goal: string,
  status: 'success' | 'failure',
  startedAt: number,
  completedAt: number,
  report: string | null,
  error: string | null,
}
```

**Exported functions:**

1. `createSchedule(data)` -- Validate data (name required; either templateId or goal required). Compute nextRunAt from `data.runAt` (timestamp) for once, or compute from `data.recurrence.time` + `data.recurrence.interval` for recurring. Generate UUID, persist, register chrome.alarm, return schedule.

2. `listSchedules()` -- Load from storage, return Object.values sorted by nextRunAt ascending (enabled first, then disabled).

3. `deleteSchedule(id)` -- Remove from storage, clear chrome.alarm, clear all associated results. Throw if not found.

4. `toggleSchedule(id, enabled)` -- Toggle enabled flag, update storage. If enabling: register chrome.alarm. If disabling: clear chrome.alarm. Return updated schedule.

5. `getNextRunTime(schedule)` -- Calculate next run timestamp from recurrence config. For 'once': return schedule.nextRunAt. For 'daily': next occurrence of schedule.recurrence.time. For 'weekly': next occurrence of schedule.recurrence.time on one of schedule.recurrence.daysOfWeek. For 'custom': schedule.nextRunAt + schedule.recurrence.periodInMinutes * 60000.

6. `executeScheduledTask(alarmName)` -- THE CRITICAL FUNCTION. Called from chrome.alarms.onAlarm in index.js.
   a. Parse scheduleId from alarmName (format: `schedule-${scheduleId}`)
   b. Load schedule from storage; if not found or not enabled, return
   c. Check `agentRunning` -- if true, log skip, update lastRunStatus='skipped', and for recurring schedules re-register alarm for next period, then return
   d. Resolve goal: if templateId, call `resolveTemplateGoal(templateId, params)`; else use schedule.goal directly
   e. Create result record with status='running', startedAt=Date.now()
   f. Find or open a tab: `chrome.tabs.query({active: true, currentWindow: true})`. If no active tab, `chrome.tabs.create({url: 'about:blank'})`. Get tabId.
   g. Call `registerInitialTab(tabId, tabInfo?.url || '')` to set up tab context
   h. Call `startAgent(goal, {tab: {id: tabId}})` -- this starts the agent loop
   i. After agent completes (listen via a post-execution hook -- see note below), update result with status='success'/'failure', completedAt, report
   j. Update schedule.lastRunAt, schedule.lastRunStatus
   k. For recurring schedules: compute nextRunAt and re-register alarm
   l. Send chrome.notifications.create with completion summary
   m. Set chrome.action.setBadgeText({text: '1'}) and setBadgeBackgroundColor (green for success, red for failure)

   **IMPORTANT on agent completion detection:** startAgent() fires runAgentLoop(goal, startTabId) which is fire-and-forget (no returned promise). The agent sets `agentRunning = false` when done. Use a polling approach: export a callback registration function `onAgentComplete(callback)` that the execution bridge registers before starting. Alternatively, use a simpler approach: after startAgent returns 'Agent started in background', set up a setInterval that checks `agentRunning` every 2 seconds. When it flips to false, capture the result. This is acceptable because the service worker stays alive during agent execution (API calls keep it active). Poll at most for 5 minutes (service worker timeout), then mark as 'failure' with timeout error.

7. `initScheduler()` -- Called from index.js on service worker startup. Loads all schedules, for each enabled schedule checks if chrome.alarm exists via `chrome.alarms.get(name)`, if not re-registers it. This handles browser restart alarm loss.

8. `getScheduleResults(scheduleId)` -- Load results for a specific schedule, sorted by completedAt desc, limited to 20.

9. `getRecentResults(limit)` -- Load all recent results across all schedules, sorted by completedAt desc.

10. `clearScheduleResults(scheduleId)` -- Delete all results for a schedule.

**Alarm naming convention:** `schedule-${schedule.id}` -- ensures unique names per schedule.

**Helper functions (internal):**
- `loadSchedules()` / `saveSchedules(schedules)` -- storage read/write for schedules object
- `loadResults()` / `saveResults(results)` -- storage read/write for results object
- `registerAlarm(schedule)` -- create chrome.alarms.create with computed `when` for once, or `when` + `periodInMinutes` for recurring
- `clearAlarm(scheduleId)` -- chrome.alarms.clear(`schedule-${scheduleId}`)
- `computeNextRun(recurrence)` -- compute next timestamp from recurrence config (time string + interval + daysOfWeek)
- `sendNotification(schedule, result)` -- chrome.notifications.create with type='basic', iconUrl, title, message

**Recurrence periodInMinutes mapping:**
- 'daily' -> 1440
- 'weekly' -> 10080
- 'custom' -> user-provided periodInMinutes

**When computing nextRunAt for recurring with time "HH:MM":**
Parse the time, get today's date at that time. If that time has already passed today, add one period. For weekly, advance to next matching dayOfWeek.

Do NOT import anything from message-protocol.js (keep scheduler focused on chrome.alarms and storage).
Do NOT import tab-context functions beyond registerInitialTab and getActiveTabId (scheduler should not manage tabs directly).

```javascript
chrome.alarms.onAlarm.addListener(async (alarm) => {

    const scheduleId = alarm.name.replace('schedule-', '');
    try {
      await executeScheduledTask(scheduleId);
    } catch (err) {
      console.error('Scheduled task execution failed:', err);
    }
  }
});
```

4. Add schedule CRUD message routing in the `wrapMessageHandler` switch, BEFORE the `default:` case:
```javascript
// Schedule CRUD
case 'schedule_list':
  return await listSchedules();

case 'schedule_create':
  if (!request.schedule) throw new Error('Schedule data required');
  return await createSchedule(request.schedule);

case 'schedule_delete':
  if (!request.id) throw new Error('Schedule ID required');
  await deleteSchedule(request.id);
  return { deleted: true };

case 'schedule_toggle':
  if (!request.id) throw new Error('Schedule ID required');
  if (typeof request.enabled !== 'boolean') throw new Error('Enabled flag required');
  return await toggleSchedule(request.id, request.enabled);

case 'schedule_results':
  if (request.id) return await getScheduleResults(request.id);
  return await getRecentResults(request.limit || 20);

case 'schedule_clear_results':
  if (!request.id) throw new Error('Schedule ID required');
  await clearScheduleResults(request.id);
  return { cleared: true };
```
