### For Users
1. **Update Extension**: Load new v10.0 extension in Chrome
2. **No Migration Required**: All settings preserved automatically
3. **Enable New Features**: Settings → Advanced → Enable v10.0 Features
4. **Configure UAP**: Optional - set up WebSocket server for external goals

### For Developers
1. **Install Dependencies**: `npm install` (uuid package added)
2. **Run Tests**: `npm test` (7,897 core tests passing)
3. **Build**: `npm run build` (if needed)
4. **Load Extension**: Chrome → Load Unpacked → Select build directory

1. **UAP Client SDK**: `import { UAPClient } from './lib/uap-client.js'`
