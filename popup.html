Welcome to Sentinel Override

Step 1 of 4

An MSP-focused browser agent that plans, acts, and reports back. Built for the techs in the trenches.

  • Audit Entra sign-ins, run Exchange message traces, configure SonicWall VPN tunnels
  • Hard-block cross-tenant actions to prevent client mix-ups
  • Generate audit-ready reports with source-cited claims
  • Remember per-client knowledge that compounds across runs

1. Pick an LLM provider

Click the gear icon (top right) → choose a provider from the catalog → paste your API key → click Detect Models → save.

Recommended:
• Anthropic Claude — best vision + reasoning, MSP-friendly
• OpenAI GPT-4.1 / GPT-5 — strong all-around
• Local: Ollama / LM Studio — free, private, slower

16 providers in the catalog with auto-detect. Switch any time.

2. (Optional) Lock in the client tenant

For Microsoft 365 work, set Expected Microsoft tenant in Settings to your client's tenant (e.g., acme.onmicrosoft.com).

The tenant chip in the header turns green when you're on the right tenant and red when you're not. Modifying actions get hard-blocked on the wrong tenant.

For multi-client work, use the Client chip (header) to switch context per run — Sentinel injects per-client knowledge automatically.

3. Try a goal

Type a goal in plain English like:

"Run a message trace in Exchange admin center for sender alice@acme.com to recipient bob@acme.com in the last 24 hours and summarize findings."

Sentinel plans, executes, and produces an investigation report with source-cited claims. Export as PDF for ticket attachment.
